# Runtime GUI assets

The interactive GUI uses locally bundled OpenAI imagegen assets created for this
project: dream_city_background.png, forest_ruins_background.png, forest_materials.png.
No third-party stock texture website was used. Blueprint paper, drafting lines,
UI, playable geometry and satin brass grain are code-rendered. No network is
needed at runtime. Historical procedural previews are in scripts/archive/.

## Fonts

The GUI uses installed Segoe UI on Windows and an installed DejaVu Sans/Arial
fallback. Font binaries are not copied or redistributed with this repository.
Typography may differ between operating systems.
